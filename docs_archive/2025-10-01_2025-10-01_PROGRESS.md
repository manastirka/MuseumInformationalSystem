# Museum Information System - Development Progress

## Project Overview
Comprehensive information system for the Natural History Museum in Belgrade (Природњачки музеј у Београду) with integrated subsystems for employee management, cultural heritage tracking, and museum operations.

## System Architecture

### Main System (Port 5555)
- **Flask-based web application** with Serbian Cyrillic interface
- **Bootstrap 5** responsive design with museum theming
- **Role-based authentication** (admin/employee permissions)
- **SQLite database** for core museum data

### Integrated Subsystems
1. **Timesheet System** (Port 5003) - Employee work tracking
2. **Mineral Database** (Port 5004) - Comprehensive mineralogy collection
3. **Cultural Heritage Registry** - Serbian protected cultural goods
