# 🔐 Модуларни систем контроле приступа
## Информациони систем Природњачког музеја у Београду

### 📋 Преглед система

Систем сада има напредну контролу приступа где админи и супер админи могу доделити приступ модулима специфичним корисницима.

---

## 🏗️ Архитектура приступа

### 🎯 **Модули система:**

#### 📊 **Систем за радне листе**
- **Статус:** `default_access: True`
- **Приступ:** Сви запослени имају приступ по default
- **Контрола:** Админ може ускратити приступ појединцима
- **Икона:** `bi-calendar-check`

#### 💎 **База минерала**
- **Статус:** `default_access: False`
- **Приступ:** Ограничен приступ
- **Овлашћени корисници:** `aca.lukovic@nhmbeo.rs` (минералог)
- **Контрола:** Админ може доделити приступ другим корисницима
- **Икона:** `bi-gem`

---

## 🔑 Правила приступа

### 👨‍💼 **Администратор (`admin`)**
- ✅ Приступ свим модулима (увек)
- ✅ Може управљати приступом других корисника
- ✅ Може доделити/укинути приступ модулима
- 🌐 URL: `/admin/manage_access`

### 👥 **Запослени**
- 📊 **Радне листе:** Аутоматски приступ за све
- 💎 **База минерала:** Само за `aca.lukovic@nhmbeo.rs`
- ⚠️ Ако немају приступ ниједном модулу - виде поруку

---

## 🖥️ Корисничко искуство

### **Пријава корисника:**
1. Унесе креденцијале
2. Систем проверава приступ модулима
3. Dashboard показује само доступне модуле

### **За кориснике без приступа:**
```
⚠️ Немате приступ ниједном модулу
Контактирајте администратора да Вам додели приступ потребним модулима система.
Ваш емејл: korisnik@nhmbeo.rs
```

### **Pokушај приступа ограниченом модулу:**
- Flash порука: "Немате дозволу за приступ бази минерала."
- Редирекција на dashboard

---

## 🔧 Админ функције

### **Управљање приступом** (`/admin/manage_access`)

#### **Преглед модула:**
- Листа свих модула са статусом приступа
- "Приступ за све" или "Ограничен приступ"
- Број овлашћених корисника

#### **Управљање корисницима:**
- Табела са свим запосленима
- Приказ тренутних модула за сваког корисника
- Дугмићи за доделу/укидање приступа

#### **Акције:**
- ✅ **Дај приступ:** POST `/admin/grant_access`
- ❌ **Укини приступ:** POST `/admin/revoke_access`
- 📝 Confirmation дијалози за све акције

## 🚀 Начин рада

### **1. Пријавите се као админ:**
```
URL: http://localhost:5555/login
Емејл: admin
Лозинка: admin123
```

### **2. Идите на управљање приступом:**
```
Dashboard → Администрација → Управљај приступом модулима
или директно: http://localhost:5555/admin/manage_access
```

### **3. Доделите приступ кориснику:**
- Пронађите корисника у табели
- Кликните зелено дугме "База минерала" (ако нема приступ)
- Потврдите у дијалогу

### **4. Укините приступ кориснику:**
- Пронађите корисника у табели
- Кликните црвено дугме "База минерала" (ако има приступ)
- Потврдите у дијалогу
