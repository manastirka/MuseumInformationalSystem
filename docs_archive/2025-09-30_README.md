# Информациони систем Природњачког музеја у Београду

Модуларна веб апликација која интегрише два система:
- **Систем за радне листе** (localSQLtesting) - управљање радним листама запослених
- **База минерала** (PrirodnjackiMuzej) - управљање колекцијом минерала музеја

## Архитектура

```
MuseumInfoSystem/
├── app.py                     # Главна Flask апликација
├── templates/                 # HTML темплејти за главни систем
├── logs/                      # Системски логови
├── localSQLtesting/          # Систем за радне листе (непромењен)
├── PrirodnjackiMuzej/        # База минерала (непромењена)
├── requirements.txt          # Python зависности
├── .env.example             # Пример конфигурације
└── README.md                # Документација
```

## Функционалности

### 🏛️ Главни систем
- Јединствена пријава за оба подсистема
- Аутентификација преко система из localSQLtesting
- Модуларна архитектура
- Адаптивни веб дизајн

### 📊 Систем за радне листе (localSQLtesting)
- Унос и управљање радним листама
- Генерисање Word докумената
- Аналитика запослених
- Администрациони панел
- Подршка за српске празнике

### 💎 База минерала (PrirodnjackiMuzej)
- Каталогизација минерала
- Претрага колекције
- Интеграција са спољним API-јима
- Увоз/извоз података

## Инсталација

1. **Клонирајте пројекат:**
   ```bash
   git clone [url]
   cd MuseumInfoSystem
   ```

2. **Инсталирајте зависности:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Конфигуришите окружење:**
   ```bash
   cp .env.example .env
   # Уредите .env фајл са вашим подешавањима
   ```

4. **Покрените апликацију:**
   ```bash
   python app.py
   ```

## Конфигурација

### База података

Систем користи две базе података:
- **MySQL** - за систем радних листи
- **SQLite** - за базу минерала

### Аутентификација

Корисничке налоге управља систем из localSQLtesting:

**За запослене:**
- Емејл: Ваша музејска емејл адреса
- Лозинка: `user` (мења се при првој пријави)

**За администратора:**
- Емејл: `admin`
- Лозинка: `admin123`

## API Endpoints

### Главни систем
- `GET /` - Почетна страница
- `GET /login` - Пријава
- `POST /login` - Аутентификација
- `GET /logout` - Одјава
- `GET /dashboard` - Главна табла
- `GET /change_password` - Промена лозинке

### Редирекције на подсистеме
- `/timesheet/*` → localSQLtesting
- `/mineral/*` → PrirodnjackiMuzej

## Архитектура аутентификације

Систем користи аутентификацију из localSQLtesting:

```python
# Увоз система аутентификације
from auth_system import auth_system

# Аутентификација корисника
user_info = auth_system.authenticate_user(email, password)

# Провера улоге
if user_info['role'] == 'admin':
    # Админ функције
```

## Проблеми и решења

### База података није доступна
1. Проверите MySQL сервис
2. Проверите корисничке податке у `.env`
3. Креирајте базу ако не постоји

### Аутентификација не ради
1. Проверите да ли постоји `auth_system` модул
2. Иницијализујте кориснике: `python -c "from auth_system import auth_system; auth_system.populate_employee_users()"`

### Подсистем није доступан
1. Проверите да ли су фајлови копирани у правилне директоријуме
2. Проверите Python path у `app.py`
