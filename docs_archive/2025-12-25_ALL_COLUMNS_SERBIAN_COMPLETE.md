## Technical Implementation

The translation system works as follows:

```javascript
// 1. Define translations for ALL fields
const fieldTranslations = {
    'catalog_number': 'Каталошки број',
    'fall_type': 'Тип пада',
    'shock_stage': 'Ниво шока',
    // ... 65 more fields
};

// 2. When creating column labels, use Serbian if available
const label = fieldTranslations[col] ||
              col.replace(/_/g, ' ').replace(/\b\w/g, l => l.toUpperCase());

// 3. Display Serbian label to user
<label for="col_${col}">${label}</label>
```

**Fallback behavior**: If a column somehow doesn't have a translation (future additions), it will auto-format the English name (e.g., `some_field` → `Some Field`). But now ALL 68 columns have translations!
