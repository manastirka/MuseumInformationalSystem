AUTOMATIC SYNCHRONIZATION:
--------------------------
The timesheet_entries table automatically stays synchronized with
timesheet_report_days through database triggers:

1. INSERT daily entry → trigger fires → category entry created
2. UPDATE daily entry → trigger fires → category entry updated
3. DELETE daily entry → trigger fires → category entry removed

This ensures:
  - Zero manual sync required
  - 100% data consistency
  - Efficient aggregate queries
  - Real-time reporting
