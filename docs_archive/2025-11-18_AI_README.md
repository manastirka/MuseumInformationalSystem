# 🤖 Музејски AI Асистент

Интелигентни асистент заснован на локалном AI-у за анализу и управљање музејским артефактима.

## 🎯 Шта је ово?

Интеграција **Ollama AI** (llama3.2:3b) са Музејским Информационим Системом која омогућава:

- 💬 Природну комуникацију о музејским колекцијама
- 🔍 Интелигентну претрагу артефаката
- 📊 Анализу минерала, експоната, књига
- 🏛️ Помоћ у каталогизацији и документацији
- 🔒 **100% локално - сви подаци остају на серверу**

## 🚀 Брзи старт

### 1. Провера Ollama (обавезно!)

```bash
# Проверите да ли је Ollama покренут
ollama list

# Ако видите llama3.2:3b - одлично!
# Ако не, покрените:
ollama serve
```

### 2. Отворите AI асистента

1. Идите на: http://localhost:5000
2. Пријавите се
3. **Администрациони панел** → **AI Алати** → **Отвори AI асистента**

### 3. Испробајте

Пробајте неколико упита:

```
Колико минерала имамо у колекцији?
```

```
Објасни систем инвентарисања
```

```
Пронађи књиге о палеонтологији
```

## 🐛 Решавање проблема

### Ollama није доступан

**Симптом**: Црвени индикатор, порука "Ollama није покренут"

```bash
# Покрените Ollama
ollama serve

# Или као сервис
sudo systemctl start ollama
```

### Спори одговори

**Узроци**:
- Превелики контекст
- Систем преоптерећен

**Решење**:
1. Кликните "Обриши контекст"
2. Затворите друге апликације
3. Користите краће упите

### Грешка "Context too large"

```
1. Кликните "Обриши контекст"
2. Учитајте само неопходне артефакте
3. Користите концизнија питања
```

## 💬 Примери разговора

### Пример 1: Анализа минерала

```
👤 Корисник: Имам минерал: беличаст, стаклени сјај, са Копаоника

🤖 AI: На основу описа, могући минерали:
     1. Кварц (најверојатније)
        - Сјај: стаклени ✓
        - Боја: често безбојан/бео ✓
        - Локалитет: уобичајен на Копаонику ✓

     2. Калцит
        - Провера: реакција са HCl (мехурићи)

     Препоручени тестови:
     - Тврдоћа (кварц = 7, калцит = 3)
     - Реакција са киселином

👤 Корисник: Тврдоћа је 7, не реагује са киселином

🤖 AI: То је **кварц**. Детаљи:
     - Минерал: SiO₂
     - Честа појава на Копаонику
     - Предложени инв. број: MIN-KOP-Q-XXXX
     - Препорука: Сликати и додати у колекцију кварца
```

### Пример 2: Планирање изложбе

```
👤 Корисник: Треба ми изложба о фосилима Србије

🤖 AI: Предлог изложбе "Фосили Србије":

     СЕКЦИЈА 1: Увод (3-5 примерака)
     - Амонити (најпрепознатљивији)
     - Трилобити
     - Фосилизовано дрво

     СЕКЦИЈА 2: Палеозоик
     - Најстарији фосили
     - ...

     СЕКЦИЈА 3: Мезозоик
     - Диносауруси (ако имамо)
     - ...

     Потребно: ~30 експоната, 15м², 3 витрине

👤 Корисник: Напиши текст за увод

🤖 AI: [Генерише текст од 150 речи]
```
