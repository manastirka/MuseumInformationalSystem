## Database Schema

**Table: `timesheet_reports`**

```sql
CREATE TABLE timesheet_reports (
    id SERIAL PRIMARY KEY,
    employee_name TEXT NOT NULL,
    month INTEGER NOT NULL,
    year INTEGER NOT NULL,
    extraordinary_tasks TEXT,  -- JSON string with work categories
    duties_summary TEXT,       -- Legacy field (not used for new data)
    is_verified BOOLEAN DEFAULT FALSE,
    is_locked BOOLEAN DEFAULT FALSE,
    verified_by TEXT,
    verified_at TIMESTAMP,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(employee_name, month, year)
);
```

**Table: `timesheet_report_days`**

```sql
CREATE TABLE timesheet_report_days (
    id SERIAL PRIMARY KEY,
    report_id INTEGER REFERENCES timesheet_reports(id),
    day INTEGER NOT NULL,
    work_in_museum NUMERIC(5,2),
    work_outside NUMERIC(5,2),
    vacation NUMERIC(5,2),
    public_holiday NUMERIC(5,2),
    paid_leave NUMERIC(5,2),
    other_leave NUMERIC(5,2),
    sick_leave_lt30 NUMERIC(5,2),
    sick_leave_gte30 NUMERIC(5,2),
    UNIQUE(report_id, day)
);
```

## How to Use the System

### For Employees - Data Entry

1. Login with your credentials
2. Click **"Радне листе"** in navigation
3. Select **"Унос радних листа"**
4. Fill in daily hours (integers only)
5. Fill in relevant work category fields (2.1 through 8)
6. Click **"Сачувај измене"** to save
7. Success message: "Радна листа је успешно сачувана!"

### For Employees - Viewing History

1. Login with your credentials
2. Click **"Радне листе"** in navigation
3. Select **"Преглед радних листа"**
4. Choose month and year from dropdowns
5. Data auto-loads (if exists)
6. Read-only mode - cannot edit from this page

### For Admins

1. Login with admin account
2. Click **"Радне листе"** in navigation
3. Goes directly to admin timesheet management
4. Can view/verify all employee timesheets
5. Can approve edit requests
