## How Dashboard System Works

### Default Behavior (First Login)

1. **Admin users** (admin, slavko.spasic, biljana.mitrovic, verica.stojanovic):
   - Default: Show only `museum_databases`

2. **Regular employees**:
   - Default: Show all modules they have access to

3. **Custom preferences**:
   - After customization, preferences are saved to `data/dashboard_preferences.json`
   - Preferences persist across sessions

### Customizing Dashboard

1. Click "Прилагоди таблу" (Customize Dashboard) button on dashboard
2. Select which modules you want to see
3. Click "Сачувај подешавања" (Save Settings)
4. Dashboard will update immediately

### Module Access Control

Access is controlled in `MODULE_ACCESS` dictionary in `app.py`:

- **default_access: True** - Everyone has access (e.g., timesheet, news)
- **default_access: False** - Only `authorized_users` have access
- **Admin role** - Always has access to everything
