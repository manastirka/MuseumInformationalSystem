## 5. Technical Details

### Statistics Calculation Logic
```python
- Minerals: FROM minerali table (SQLite)
- RRUFF: FROM rruff_minerals table (SQLite)
- Other collections: COUNT from in-memory dictionaries
- Images: FROM ImageStorageEngine metadata
- Coverage: (specimens_with_images / total_specimens) * 100
```

### QR Code URL Structure
```
Base URL: http://192.168.144.48
Minerals: /admin/mineral_detail/{id}
Others: /admin/collection_database/{type}?highlight={catalog_number}
```

### QR Code Technical Specs
- **Version**: QRCode v1 (21x21 modules)
- **Box Size**: 10 pixels per module
- **Border**: 2 modules (quiet zone)
- **Format**: PNG, black on white
- **Encoding**: Base64 for HTML embedding
- **Error Correction**: Default (medium)

## 11. Enhanced QR Code Generation Feature (ADDED)

### ✅ Specimen Selection and Filtering System

**New Routes Added:**
- `/admin/qr_select/<collection_type>` - Specimen selection interface with filters
- `/admin/qr_labels_selected/<collection_type>` - Generate QR codes for selected specimens

**Features Implemented:**

#### Filter Criteria by Collection Type:

**Minerals:**
- Inventory number range (from/to)
- Location (where specimen is stored)
- Locality (where found)

**Other Collections (Meteorites, Botany, Paleozoology):**
- Catalog number search
- Name/scientific name search
- Location search

#### Selection Interface:
- **Interactive Table**: Shows all matching specimens
- **Checkbox Selection**: Click row or checkbox to select
- **Bulk Actions**:
  - Select All button
  - Deselect All button
  - Select All checkbox in header
- **Live Counter**: Shows number of selected specimens
- **Generate Button**: Only enabled when specimens are selected

#### Filter Examples:
```
# Minerals in location 180:
?location=180

# Minerals inventory 1-100:
?inv_from=1&inv_to=100

# Meteorites containing "Jelica":
?name=Jelica

# All filters combined:
?inv_from=1&inv_to=500&location=180&locality=Serbia
```

### How to Use:

1. **Navigate to QR Generator**: http://192.168.144.48/admin/qr_generator
2. **Choose Option**:
   - "Генериши за све (прве 100)" - Generate for first 100 specimens
   - "Изабери примерке" - Select specific specimens
3. **Apply Filters** (optional):
   - Enter filter criteria (inventory range, location, etc.)
   - Click "Примени филтере"
4. **Select Specimens**:
   - Click rows or checkboxes to select
   - Use "Изабери све" for all visible
5. **Generate QR Codes**:
   - Click "Генериши QR кодове за изабране (N)"
   - Print labels as usual

### Benefits:

- **Targeted Printing**: Only print QR codes you need
- **Efficient**: Filter by storage location, print only what's in that cabinet
- **Flexible**: Combine multiple filter criteria
- **User-Friendly**: Visual feedback, row highlighting, live counter
- **Performance**: Handles 1000+ specimens smoothly
