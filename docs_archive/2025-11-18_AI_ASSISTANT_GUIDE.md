# Музејски AI Асистент - Водич

## Преглед

Музејски AI Асистент је интелигентни систем заснован на локалном Ollama AI моделу (llama3.2:3b) који помаже у анализи, претрази и управљању музејским артефактима.

## Карактеристике

### 🤖 Основне могућности

- **Анализа артефаката**: Детаљна анализа минерала, експоната, књига, записа о прстенацији
- **Природна претрага**: Претраживање колекција природним језиком
- **Контекстуална свест**: Памћење разговора и учитаних артефаката
- **Каталогизација**: Помоћ у документацији и стандардизацији података
- **Препоруке**: Предлози за изложбе, истраживања, допуну колекција

### 🔒 Приватност и безбедност

- **100% локално**: Сви подаци остају на вашем серверу
- **Офлајн рад**: Не захтева интернет конекцију
- **Без слања података**: Ниједан податак не напушта музејску мрежу

## Инсталација и подешавање

### Предуслови

1. **Ollama** - AI платформа
2. **Model llama3.2:3b** - Оптимизован за RTX 2060 (6GB VRAM)

### Инсталација Ollama

```bash
# Преузимање и инсталација
curl -fsSL https://ollama.com/install.sh | sh

# Или на Fedora:
sudo dnf install ollama

# Преузимање модела
ollama pull llama3.2:3b

# Покретање Ollama сервиса
ollama serve
```

### Провера статуса

```bash
# Провера да ли је Ollama покренут
ollama list

# Требало би да видите:
# NAME           ID              SIZE      MODIFIED
# llama3.2:3b    a80c4f17acd5    2.0 GB    ...
```

## Напредне функције

### Коришћење контекста

AI асистент памти све што сте му показали у току сесије:

1. Учитајте неколико артефаката
2. Поставите питања која их упоређују
3. Тражите анализе и препоруке

**Пример:**

```
[Учитајте 3 минерала са Копаоника]

Упореди ове минерале и предложи изложбену целину.
Који је најретији?
Шта недостаје за комплетну приказ геологије Копаоника?
```

### Чишћење контекста

Када прелазите на нову тему, обришите контекст:

- Кликните на дугме **"Обриши контекст"**
- Започните нови разговор

### Праћење искоришћености контекста

У заглављу чета видите:
- **Тренутни токени**: Колико простора користите
- **Максимум**: 16,384 токена (~12,000 речи)
- **Проценат**: Колико простора је попуњено

**Савет**: Када достигнете 80%, обришите стари контекст.

## API Интеграција

### Ендпоинти

#### POST /api/llm/chat
Пошаљи поруку AI асистенту

```json
{
  "message": "Анализирај овај минерал"
}
```

#### POST /api/llm/context/mineral/{id}
Додај минерал у контекст

#### POST /api/llm/context/book/{id}
Додај књигу у контекст

#### POST /api/llm/context/bird_ringing/{id}
Додај запис о прстенацији у контекст

#### POST /api/llm/context/clear
Обриши контекст

#### GET /api/llm/context/usage
Провери искоришћеност контекста

### Оптимизација

- Користите кратке, јасне упите
- Обришите контекст када није потребан
- Избегавајте превише дуге разговоре

## Решавање проблема

### Ollama није доступан

**Симптом**: Црвени индикатор статуса

**Решење**:
```bash
# Проверите статус
systemctl status ollama

# Покрените ако није активан
ollama serve

# Или на системском нивоу
sudo systemctl start ollama
```

### Спори одговори

**Могући узроци**:
- Превелик контекст (обришите старе поруке)
- Систем преоптерећен (затворите друге апликације)
- Модел није оптималан

**Решење**:
```bash
# Користите мањи модел
ollama pull llama3.2:1b

# Или у app.py промените:
# model="llama3.2:1b"
```

### Грешка "Context too large"

**Решење**:
1. Кликните "Обриши контекст"
2. Учитајте само потребне артефакте
3. Будите концизнији у питањима

## Најбоље праксе

### ✅ Препоручено

- Јасна и специфична питања
- Учитавање релевантних артефаката пре анализе
- Редовно чишћење контекста
- Коришћење српског језика

### ❌ Избегавајте

- Презагушен контекст (>10 артефаката одједном)
- Неодређена питања ("Реци ми нешто")
- Мешање језика (српски/енглески)
- Очекивање фотографске меморије (AI не памти преко сесија)

## Безбедност података

### Шта AI види:

- Тренутни разговор
- Учитани артефакти у контексту
- Системски prompt (инструкције)

### Шта AI НЕ види:

- Друге разговоре
- Податке које нисте учитали
- Лозинке и осетљиве информације

### Где се подаци чувају:

- **Разговори**: У меморији (губе се при рестарту)
- **Модел**: Локално на серверу
- **Артефакти**: У бази података (нетакнути)
