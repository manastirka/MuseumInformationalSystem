## 🔧 SQL Упити за администрацију

### Провера свих активних корисника:
```sql
SELECT id, email, full_name, position, is_active, last_login_at
FROM users
WHERE is_active = TRUE
ORDER BY last_login_at DESC NULLS LAST;
```

### Провера корисника који се никада нису логовали:
```sql
SELECT id, email, full_name, position
FROM users
WHERE is_active = TRUE AND last_login_at IS NULL;
```

### Провера admin корисника:
```sql
SELECT u.id, u.email, u.full_name, r.name as role
FROM users u
JOIN roles r ON u.role_id = r.id
WHERE u.is_active = TRUE AND r.name = 'admin';
```
