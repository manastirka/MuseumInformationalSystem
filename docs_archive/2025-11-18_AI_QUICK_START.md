# AI Асистент - Брзи Старт

## 🚀 За 3 минута до првог коришћења

### 1. Проверите Ollama (30 секунди)

```bash
# Проверите статус
ollama list

# Ако није покренут:
ollama serve
```

### 2. Отворите AI асистента (30 секунди)

1. Идите на http://localhost:5000
2. Пријавите се
3. Администрациони панел → **AI Алати** → **Отвори AI асистента**

### 3. Пробајте (2 минута)

Брзи упити:

```
Колико минерала имамо?
```

```
Које експонате имамо из палеонтологије?
```

```
Објасни систем инвентарисања
```

## ⚡ Брзе типке

- **Enter** - Пошаљи поруку
- **Shift+Enter** - Нови ред
- **Обриши контекст** - Започни нови разговор

## 💡 Савети

### ✅ Ради добро

- Јасна питања: "Колико минерала имамо са Копаоника?"
- Специфични захтеви: "Напиши текст за табелу о кварцу"
- Контекстуална питања: "Упореди ове три минерала"

### ⚠️ Избегавајте

- Предуге разговоре (>10 размена)
- Неодређена питања ("Реци ми нешто")
- Очекивање да памти преко сесија

## 🔧 Брзо решавање проблема

### Није доступан?

```bash
ollama serve
```

### Спор?

1. Кликните "Обриши контекст"
2. Користите краће упите

### Грешка?

Проверите логове:
```bash
tail -f /home/aleksandarlukovic/MuseumInfoSystem/logs/museum_info_system.log
```

## 📊 Праћење контекста

У заглављу чета:
- **Зелени** (<60%): Одлично
- **Жути** (60-80%): Пажња
- **Црвени** (>80%): Обришите контекст!
