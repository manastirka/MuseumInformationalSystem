# Радне листе — базелини (закључани) стадијум

**Тег:** `baseline-radne-liste-2026-07-28`
**Регресиони пакет:** `test_radne_liste_baseline.py`

Ово је потврђено-исправно стање модула месечних радних листа. Корисник је
потврдио да цео ланац ради беспрекорно на продукцији; овај базелин га
**закључава** — сваки решен баг чува по један именован тест, па повратак на
стару грешку одмах обара пакет.

## Како пустити цео пакет (једна команда)

```bash
SECRET_KEY=test-secret REDIS_URL='' FLASK_ENV=testing \
SESSION_TYPE=filesystem SESSION_FILE_DIR=logs/qa_flask_session \
RATELIMIT_STORAGE_URL=memory:// python3 -m pytest -q test_radne_liste_baseline.py
```

Очекивано: **све зелено** (22 теста). Делови који пишу у базу прескачу се без
PostgreSQL-а; `.doc` конверзија прескаче се без LibreOffice-а (`soffice`). Пакет
је идемпотентан и самочистећи — користи изоловане `*@example.invalid` е-адресе
и чисти за собом.

## Обавезно понашање које је закључано

1. **Матрица присуства се чува end-to-end.** Попуна → чување уписује тачне
   редове у `timesheet_report_days` → поновно отварање форме враћа исте
   вредности. Пошто је чување `DELETE`-па-`INSERT`, **празан re-save не сме тихо
   да обрише** већ попуњену листу (враћа `VALIDATION_ERROR`, подаци остају).
2. **Враћена листа на допуну је изменљива власнику — и старија од претходног
   месеца.** Враћање (`REJECTED`) отвара 24h прозор (`editable_until`) који гази
   календарски рок за тај извештај.
3. **Двостепено одобрење.** Један потпис = `SUBMITTED` (није одобрено); шеф +
   директор = `APPROVED`; враћање на допуну ресетује ОБА потписа.
4. **Директор потврђује листе из СВИХ одељења; шеф само своје.**
5. **Админ откључавање уноса по кориснику.** Не-админ добија `403`; поднета
   листа се не дира. **Механизам „захтева за откључавање" не постоји** —
   откључава искључиво админ/директор.
6. **Увоз из Word-а.** `.docx` (три варијанте шаблона: дани-редови, дани-колоне,
   латиница) и `.doc` (детекција по magic бајтовима + конверзија кроз
   LibreOffice) дају исту канонску матрицу. Увоз је **искључиво админ функција**
   (серверска заштита на свим рутама). Архивски ток → `APPROVED`; текући →
   `SUBMITTED`.
7. **Раздвајање текућих и архивских листа.** Текући преглед = ручни унос текуће
   године; архива = остало. Ништа се не брише; запослени види своју историју по
   избору године.
8. **Бирач година је изведен из података** — од најстарије постојеће листе до
   текуће године (нпр. 2011 видљива ако постоји листа из 2011).

## Правило одржавања

Ако неки тест овде падне, то значи да је **закључана гаранција регресирала** —
тест се НЕ прилагођава да прође, него се поправља код. Нови баг у овом модулу →
најпре репродукциони тест овде, па поправка.

## CI

Пакет се обавезно извршава у CI-ју кроз `npm run qa:python` (посао *Python QA* у
`.github/workflows/qa.yml`).
